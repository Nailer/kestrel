## Items the organizers' page requires that you must supply yourself
1. Project name, **the email you signed up with at Otari.ai**, one-line description → above.
2. **Public** GitHub repo link + **branch name** (`hackathon`) → above.
3. **Link to the first commit where Otari came in** → `41a25e52d63caea1af691d1f970fe5d0496b4d1b`.
4. **Otari features used** → list inside `description.md`.
5. **Any PRs or issues opened on mozilla-ai/otari** → see `submission/ISSUE-DRAFTS.md` (optional but listed on the form).
6. **3–5 min demo video** (your screen + your own voice; no AI voiceover) → `docs/VIDEO-SCRIPT.md`.
7. **Feedback**: a 3–5 min feedback screen recording AND written answers (the page says "either or both"; do both to be safe). Your own words — `docs/FEEDBACK-LOG.md` is only a memory aid.
